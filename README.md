# Cadastro de Produtos para Múltiplas Lojas de E-Commerce 🛒📦

![Python](https://img.shields.io/badge/Python-3.x-blue?style=flat&logo=python)
![Pandas](https://img.shields.io/badge/Data-Pandas-150458?style=flat&logo=pandas)
![Automation](https://img.shields.io/badge/Automation-PyAutoGUI-brightgreen)

Este projeto tem como objetivo centralizar e organizar o cadastro de produtos de três lojas de e-commerce que possuem portfólios compartilhados. Para isso, foi criada uma solução que armazena e gerencia os links de todos os produtos disponíveis em cada uma das lojas, permitindo uma melhor gestão, automação de processos e análise das informações.

## 📌 Descrição e Objetivo

A principal meta é resolver a fragmentação de dados entre múltiplas vitrines virtuais. Ao centralizar os links e informações, o projeto facilita a manutenção da consistência dos dados entre as lojas e agiliza o processo de cadastro.

## 🏗️ Funcionalidades Implementadas

* **Cadastro Unificado de Produtos:** Registra os produtos disponíveis simultaneamente nas três lojas.
* **Mapeamento de Links:** Associação de cada produto (SKU/Nome) aos seus respectivos URLs em cada plataforma de e-commerce.
* **Estruturação de Dados:** Organização eficiente da base para facilitar consultas rápidas e viabilizar futuras integrações.

## 🚀 Tecnologias Utilizadas

* **Linguagem:** Python 🐍
* **Bibliotecas:**
    * `pandas` (Manipulação e estruturação da base de dados)
    * `pyautogui` (Automação de tarefas de interface/cadastro)

## 📊 Benefícios do Projeto

* **Agilidade:** Facilidade no gerenciamento e atualização de produtos em massa.
* **Centralização:** Acesso rápido e organizado às informações de diferentes frentes de loja.
* **Escalabilidade:** Base preparada para futuras integrações com sistemas de precificação dinâmica e controle de estoque.
